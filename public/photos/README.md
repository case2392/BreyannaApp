# Studio photos

Drop your photos into this folder using exactly these file names and they'll
appear automatically on the site (no code changes needed). Until a file is
added, the site shows a tasteful brand-colored panel in its place.

| File name        | Where it shows on the site                         |
| ---------------- | -------------------------------------------------- |
| `hero.jpg`       | Large background image at the top of the homepage  |
| `about.jpg`      | "Our heart" / about section                        |
| `cycle.jpg`      | Community gallery (left)                            |
| `community.jpg`  | Community gallery (center)                          |
| `movement.jpg`   | Community gallery (right)                           |

Tips:
- JPG or PNG both work. Keep them reasonably sized (1–2 MB each is plenty).
- Landscape (wide) photos look best for `hero.jpg`; the others can be any shape.
- Easiest way to add them: on GitHub, open this `public/photos` folder →
  "Add file" → "Upload files" → drag your photos in (renamed as above) →
  "Commit changes". The site updates automatically a minute later.
